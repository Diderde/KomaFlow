# 静态资源

## 文件一览

| 文件 | 用途 | 来源 |
| --- | --- | --- |
| `logo.png` / `logo_watermark.png` | 预览区水印（256px） | **本项目自绘**，脚本现画 |
| `logo_ico` / `logo_{16..96}.png` | 顶栏徽标、标题栏、任务栏图标 | **本项目自绘**，见下面「图标」 |

## 一、图标（`tools/build_logo_assets.py`）

**为什么必须分档**：定稿标记（深蓝容器 + 白狐首 + 湖青耳 + 圆内 `MMD` / `Dock`）
在 ≥48px 很好看，但缩到 16/24px 就只剩一团白 —— 里面那两行字成了糊点。
这不是导入出错，而是**标记本身在极小尺寸下撑不住**：品牌资产包自己产的
`02_图标/_极小尺寸放大.png`（32/24/16 三个尺寸放大 9 倍）也是这个结果。

| 尺寸 | 用哪版 | 谁在用 |
| --- | --- | --- |
| 16 / 24 / 26 / 32 / 40 | **无字简化版**：白圆狐首 + 描边耳 + 挖空播放三角 | 任务栏 / 标题栏（16、32）、标题栏自绘（26）、顶栏徽标（40） |
| 48 及以上 | 完整标记（带 `MMD` / `Dock` 字样） | 水印（256）、需要大图的地方 |

**再生成**：

```bash
python tools/build_logo_assets.py # 覆盖同名文件，代码不用改
python tools/build_logo_assets.py --check # 只看分档，不写文件
```

验收图（白底 / 深底各一行，右下角带 3 倍像素放大）：`work/logo_sizes_check.png`

> ⚠️ 两个坑记下来：
> 1. **小尺寸别塞字**。第一版想在 16px 里保住字样，结果就是一团白。
> 2. **PIL 存多档 ICO**：`frames[0].save(..., sizes=[...])` 只会留**一档**
> （实测写出 0.8 KB 的 16×16 单档，原来是 40 KB 的七档）。
> 正确写法是拿最大那张当底、其余档走 `append_images`；
> 脚本里加了断言，写不够档数就直接报错。

## 二、商标现状：已彻底移除旧字样

产品改名 **KomaFlow** 之后，图标里不再有任何字母：

| 位置 | 状态 |
| --- | --- |
| **全部尺寸（16 ~ 256）与 `.ico`** | ✅ **无任何字母** —— 只有深蓝圆角容器 + 白圆狐首 + 湖青描边耳 + 播放三角 |
| **产品名 `KomaFlow`** | ✅ 不含 `MMD` / `MikuMikuDance` / `VOCALOID` / `初音ミク` / `Blender` |
| **不再依赖外部定稿图** | ✅ 形状全部由 `tools/build_logo_assets.py` 现画，构建可复现 |

做法：把 `FULL_MARK_MIN` 设成 `0`，于是**任何尺寸都走无字形状**；
`build_full_mark()` 保留函数名但内部直接复用无字版，历史调用点不会报错。

> ⚠️ 这消除的是"名称与图形里使用他人商标"的风险。
> **不等于已完成商标检索** —— 对外发布前仍应自行查一遍目标地区的商标库与同名软件。

## 三、角色元素怎么落到界面上的

吉祥物与装饰取自本项目自有的 AI 生成角色「本项目吉祥物」，满足 
「产品图标、界面配图必须为原创或可明确可商用授权」。元素与落点：

| 她的元素（设定文档里写死的） | 落在哪 | 为什么放这 |
| --- | --- | --- |
| **狐耳**（耳内白绒 / 耳尖白毛） | 顶栏 **LOGO 后面** —— 耳朵从圆徽标上方冒出来 | 第一识别点，一眼看出是这个角色的产品 |
| **尾巴**（"尾巴划出一道弧线"） | 预览区**两侧水印**（`deco_tail_l/r.png`） | 尾巴天生是一条 S 形大弧，比抽象飘带有指向性 |
| **枫红 `#B33A2B` → 暖橘 `#E88B3C`** | **进度条填充**做成横向渐变 | 进度条是界面上最"动"的元素，用她的主色最贴切 |
| **琥珀竖瞳 `#D89A2B`** | **运行中卡片的角标** + 卡片描边转枫红 | 竖瞳是她的标志；暖色只出现在"正在发生"的地方 |
| **银铃 + 红绳**（设定里是"跳舞时的节拍器"） | **完成态卡片的图标** | "节拍器"对应渲染收尾，比通用对勾有味道 |
| **亚麻 `#D9C09A`** | 耳内 / 卡片暖底 | 把整体从冷调拉回暖调 |
| 立绘本体 | 预览区**右下角，缩小当助手** | 不挡工作区；空态提示文字居中 |

配色仍以**深蓝为主、暖色为辅**：暖色只在"正在发生"处出现（进度、运行中卡片），
静态结构保持深蓝 —— 否则整个界面会变成一片红。

> 角色色定义集中在 `src/komaflow/ui/theme.py` 的 `MAPLE / ORANGE / LINEN / AMBER / CORD / BROWN`。

### `mascot.png` 的来源与再生成

| 项 | 内容 |
| --- | --- |
| 角色 | **本项目吉祥物**（本项目吉祥物）· 现代都市狐耳少女 · 街头舞者 |

## 四、本仓库不含第三方角色形象

没有 `MIKU` / `初音` / `VOCALOID` 字样，也没有任何官方 Logo。

### 为什么不做初音未来（评估过，结论是不做）

官方条款（Crypton Future Media，2026-03-10 版）：
[ピアプロ｜キャラクター利用のガイドライン](https://piapro.jp/license/character_guideline)、
[PCL 要約](https://piapro.jp/license/pcl/summary)、
[For Creators（英文）](https://piapro.net/intl/en_for_creators.html)

| 条款 | 内容 |
| --- | --- |
| PCL 的适用范围 | **仅限「非営利かつ無償」**的二次创作公表：SNS / 博客发布、无偿展示与分发等 |
| **D-2(1)** | **法人**的任何利用（不论营利与否）**都需单独签约** |
| **D-2(2)** | **个人**以**营利为目的**的利用（**明确包含广告、宣传、広報用途**）需单独签约 |
| **D-2(3)** | 超出「爱好或学校教育」规模的利用需单独签约 |
| **D-1（絶対NG）** | **让人误以为是官方产品**的利用 |
| **E 节** | 官方图片不得原样使用（仅少数例外并须特定署名）；**描图 / トレース禁止**，只有手绘模写且在严格条件下才行 |
| その他 6 | **「初音ミク」是 Crypton Future Media 的注册商标** |

把该角色做成**软件界面的内置配图**，属于"把他人角色当作自家产品的品牌元素"——
踩 **D-1**，也超出 PCL 的授权范围（软件产品不是"个人非营利公表"）。

**再加上本项目自己的 / / 14.7 已明文禁止内置第三方角色形象，并列为发布前一票否决。**

**所以：不内置、也不生成任何初音未来的角色图。** 想要那个气质，
就用上文的抽象三件套 —— 青色调 + 音符 + 飘带。

> 若使用者自行替换 LOGO 等资源，权利与责任由放置者承担。

## 五、装饰图是怎么做出来的

Tk 的 Canvas **不做抗锯齿**，曲线和圆角一定有台阶。所以装饰一律**预渲染**：

```bash
python tools/render_ui_assets.py # 需要 Pillow；开发期工具，不参与运行时
```

用 Pillow **4 倍超采样**画好再 LANCZOS 降采样 —— 像素里已经带着抗锯齿，
程序里 1:1 贴上去，边缘就是干净的。生成的 PNG 随包分发，
程序本身**依然零第三方运行时依赖**（NFR-16）。
